# Radians
There is another way of measuring angles, radians.
$$\text{degrees}\leftrightarrow \text{radians}$$
$$\text{centimeters}\leftrightarrow\text{inches}$$
"One radian is the angle **subtended** at the center of a circle by an arc of one length radius."

![[Radians deffinition.excalidraw]]

| Arc          | Angle in degrees | Angle in radians                             |
| ------------ | ---------------- | -------------------------------------------- |
| Whole circle | 360°             | $\frac{\pi d}{r}=\frac{\pi\times2r}{r}=2\pi$ |
| Half         | 180°             |                                              |

#### Exact values:

| 180° | $\pi$            |
| ---- | ---------------- |
| 90°  | $\frac{\pi}{2}$  |
| 45°  | $\frac{\pi}{4}$  |
| 60°  | $\frac{\pi}{3}$  |
| 30°  | $\frac{\pi}{6}$  |
| 150° | $\frac{5\pi}{6}$ |

### Examples:
1. Convert 137 into radian measure
180° is $\pi$ radians
1° is $\frac{\pi}{180}$
137° is $\frac{\pi}{180}\times137=2.3411$...radians
2. find the exact value of $\cos\frac{7\pi}{4}$ withous a calculator
$\cos\frac{7\pi}{4}=\cos(7\times45)°$
$=\cos315°$
$=\cos45°$
$=\frac{1}{\sqrt2}$ 
(The exact trig values used here come from the tables above.)
