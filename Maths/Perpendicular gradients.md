# Perpendicular Gradients

If two lines are perpendicular, the product of their gradients is $-1$:

$$m_1 \times m_2 = -1$$

So if one line has gradient $m$, a perpendicular line has gradient $-\frac{1}{m}$.

## Example:
Line $L_1$ has equation $y = 3x + 2$.
Gradient of $L_1$ is $3$.
A line perpendicular to $L_1$ has gradient $-\frac{1}{3}$.
