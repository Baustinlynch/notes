# Indices - Fractional Indices

## Fractional indices
For any number $a$ and any integers $m$,$n$:
$$a^{\frac{1}{n}}=\sqrt[n]{a}$$
$$a^{\frac{m}{n}}=(\sqrt[n]{a})^m=\sqrt[n]{a^m}$$

### Write as roots
1. $x^{\frac{1}{2}}=\sqrt{x}$
2. $x^{\frac{1}{3}}=\sqrt[3]{x}$
3. $x^{\frac{3}{2}}=(\sqrt{x})^3=\sqrt{x^3}$
4. $x^{\frac{2}{3}}=\sqrt[3]{x^2}$
5. $4x^{\frac{5}{2}}=4\sqrt{x^5}$
6. $x^{-\frac{1}{2}}=\frac{1}{x^{\frac{1}{2}}}=\frac{1}{\sqrt{x}}$
7. $x^{-\frac{4}{3}}=\frac{1}{x^{\frac{4}{3}}}=\frac{1}{\sqrt[3]{x^4}}$
8. $5x^{-\frac{2}{3}}=\frac{5}{x^{\frac{2}{3}}}=\frac{5}{\sqrt[3]{x^2}}$

### Write as a root and evaluate
1. $4^{\frac{1}{2}}=\sqrt{4}=2$
2. $(-8)^{\frac{1}{3}}=\sqrt[3]{-8}=-2$
3. $25^{\frac{3}{2}}=(\sqrt{25})^3=5^3=125$
4. $16^{-\frac{1}{2}}=\frac{1}{16^{\frac{1}{2}}}=\frac{1}{\sqrt{16}}=\frac{1}{4}$
5. $27^{-\frac{1}{3}}=\frac{1}{27^{\frac{1}{3}}}=\frac{1}{\sqrt[3]{27}}=\frac{1}{3}$
6. $100^{-\frac{3}{2}}=\frac{1}{100^{\frac{3}{2}}}=\frac{1}{(\sqrt{100})^3}=\frac{1}{10^3}=\frac{1}{1000}$

### Write in index form
1. $\sqrt{x^5}=x^{\frac{5}{2}}$
2. $\sqrt[3]{x^5}=x^{\frac{5}{3}}$
3. $\sqrt[4]{x}=x^{\frac{1}{4}}$
4. $\frac{1}{\sqrt{x^3}}=\frac{1}{x^{\frac{3}{2}}}=x^{-\frac{3}{2}}$
