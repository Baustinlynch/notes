# Indices - Multiplying Powers

## Multiplying powers with the same base
$$a^n\times a^m=a^{n+m}$$
$n$ and $m$ can be **any** number.

### Examples: Simplify by writing in index form
1. $8^5\times8^9=8^{14}$
2. $a^4\times a^6=a^{10}$
3. $y^7\times y^{-3}\times y=y^{7+(-3)+1}=y^5$
4. $a^4\times b^5\times a^3\times b^{-3}=a^7\times b^3$
5. $3x^5\times 4x^4=12x^9$
