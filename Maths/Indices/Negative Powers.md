# Indices - Negative Powers

## Negative powers
For negative indices,
$$a^{-n}=\frac{1}{a^n}$$

### Examples: Write with a positive index and evaluate
1. $4^{-1}=\frac{1}{4^1}=\frac{1}{4}$
2. $10^{-2}=\frac{1}{10^2}=\frac{1}{100}$
3. $1^{-5}=\frac{1}{1^5}=1$
4. $6\times 2^{-3}=6\times \frac{1}{2^3}=\frac{6}{8}=\frac{3}{4}$

### Examples: Write with a positive index
1. $x^{-5}=\frac{1}{x^5}$
2. $3x^{-1}=3\times \frac{1}{x}=\frac{3}{x}$
3. $(3x)^{-1}=\frac{1}{(3x)^1}=\frac{1}{3x}$
4. $(x^2)^{-3}=\frac{1}{(x^2)^3}=\frac{1}{x^6}$
