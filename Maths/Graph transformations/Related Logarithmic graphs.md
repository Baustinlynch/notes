### Examples:
1. This is the graph of $f(x)=\log_{a}x$
   Find the value of $a$.
(For the features of the basic [[Logarithmic Functions|logarithmic function]] used here, see the main note.)
```desmos-graph
top=1.5; bottom=-1.5;
left=-0.5; right=4;
---
y= \log_3 x
(1,0)|label:1
(3,1)|label:(3,1)/(a,1)
```
$$y=\log_{a}x$$
$$1=\log_{a}3$$
$$a^{1}=3$$
$$a=3$$
2. This is the graph of $f(x)=\log_{3}(x+k)$
   Find the value of $k$.
```desmos-graph
left=-2;right=3.5
top=2;bottom=-1;
---
y=\log_3(x+2)
(-1,0)|label:(-1,0)
(1,0)|label:(1,0)
```
$$y=\log_{3}(x+k)$$
$$f(x)\to f(x+k)$$
$$(1,0)~~~~~~~~(-1,0)$$
$$\Delta x=2=k$$
