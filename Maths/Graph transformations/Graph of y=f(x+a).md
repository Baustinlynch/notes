For the graph of $y=f(x+a)$, slide the graph of $f(x)$horizontally.
- if a > 0 the graph slides to the left by $a$
- if a < 0 the graph slides to the right by $a$
### Example:
Find the coordinates of A', B', C', the images of A, B, C, under the transformation f(x-2).
Label the points on your graph.

%% col-start %%

%% col-break:b:blue-soft,t:blue %%

| f(x)    |
| ------- |
| A(0,0)  |
| B(3,-9) |
| C(6,0)  |

%% col-break:b:red-soft,t:red %%

| f(x)     |
| -------- |
| A'(2,0)  |
| B'(5,-9) |
| C'(8,0)  |


%% col-end %%
