## Example:
This is the graph of the function $f(x)=ba^x$.
Find the values of $a$ and $b$, where $a$,$b>0$.
There are 2 ways that we can do this problem, graphically, and algebraically.
(For the features of the basic [[Exponential Function|exponential function]] used here, see the main note.)
### Graphically
```desmos-graph
left=-1.25; right=2.5;
top=52; bottom=-2.5
---
y = 3*4^x
(0,3)|label:(0,3)
(2,48)|label:(2,48)
```
In a standard exponential graph, $a^x$ is always equal to (0,1), and in our graph $ba^x$ is equal to (0,3), so $b=3$.
Because $b=3$, we can find that $y=3a^x$, and the line passes through (2,48), so if we put that point into the equation, we find that $48=3a^2$ ($x=2$,$y=48$), so we just need to solve that algebraic equation: $16=a^2$, $a=\pm4$ so $a=4$.

### Algebraically
By putting the point (0,3) into the equation, we get $3=ba^0$, so $b=3$. To find $a$ we use the same algebraic method as we did when finding it graphically: Because $b=3$, we can find that $y=3a^x$, and the line passes through (2,48), so if we put that point into the equation, we find that $48=3a^2$ ($x=2$,$y=48$), so we just need to solve that algebraic equation: $16=a^2$, $a=\pm4$ so $a=4$.
