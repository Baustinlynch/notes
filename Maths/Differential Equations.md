A **Differential equation** is an equation with a derivative in it.
$$\frac{dy}{dx}=7x-1~~~~ \frac{ds}{dt}3t^2-7t+4$$
They can be solved to find an expression for $y$,$s$ etc.
This can be done by **integrating**, for example:
$$\frac{dx}{dy}=8x$$
$$\int \frac{dy}{dx}dx=\int 8x~dx$$
$$\underline{y=4x^2+c}$$
==🔴^^General equation^^==
More information is needed to find the value of $c$.
$$\underline{y=4x^2+c}$$
e.g. if point $(3,5)$ lies on the curve then
$$5=4(x)^2+c$$
$$5=4(9)+c$$
$$5=36+c$$
$$c=-31$$
$$y=4x^2-31$$
==🔴^^Particular equation^^==
The general solution to any differential equation represents a family of curves.
