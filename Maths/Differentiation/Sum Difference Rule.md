# Differentiation - Sum/Difference Rule

> [!NOTE] Rule
> If $f(x)=g(x)+h(x)$
> then $f'(x)=g'(x)+h'(x)$

### Examples
Differentiate:
1. $f(x)=x^4+2x^3-7x^2-6x+2$
   $f'(x)=4x^3+6x^2-14x-6$
2. $f(x)=\frac{\sqrt{x}}{3}+\frac{1}{x} = \frac{1}{3}x^{1/2}-x^{-1}$
   $f'(x)=\frac{1}{6}x^{-1/2}+x^{-2}$
