# Differentiation - Trig Functions

### Rules

| $f(x)$    | $f'(x)$     |
| --------- | ----------- |
| $\sin ax$ | $a\cos ax$  |
| $\cos ax$ | $-a\sin ax$ |

### Examples
1. Differentiate $y=6\sin x+5\cos x-7x^2$ with respect to $x$
   $$\frac{dy}{dx}=6\cos x-5\sin x-14x$$

2. Find the gradient of the graph $y=\sin x+2\cos x$ at $x=\frac{\pi}{3}$
   $$\frac{dy}{dx}=\cos x-2\sin x$$
   $$m=\cos\left( \frac{\pi}{3}\right)-2\sin\left( \frac{\pi}{3} \right) = \frac{1}{2}-2\left( \frac{\sqrt{3}}{2} \right) = \frac{1-\sqrt{3}}{2}$$

3. Find the equation of the tangent to the curve $y=\cos x$ at $x=\frac{\pi}{6}$
   $(a,b) = \left( \frac{\pi}{6},\frac{\sqrt{3}}{2} \right)$
   $$m = -\sin\left( \frac{\pi}{6} \right) = -\frac{1}{2}$$
   $$y-\frac{\sqrt{3}}{2}=-\frac{1}{2}\left( x-\frac{\pi}{6} \right)$$
   $$y=-\frac{1}{2}x+\frac{\pi}{12}+\frac{\sqrt{3}}{2}$$
