# Differentiation - Increasing and Decreasing Functions

If $f(x)$ is **increasing** the gradient of the tangent to the curve is positive so $\frac{dy}{dx}>0$ or $f'(x)>0$.
If $f(x)$ is **decreasing**, the gradient of the tangent to the curve is **negative** so $\frac{dy}{dx}<0$ or $f'(x)<0$.

### Examples
1. Is $f(x)=5x-x^2$ increasing or decreasing at $x=3$?
   $$f'(x)=5-2x$$
   $$f'(3)=5-2(3) = -1$$
   $f(x)$ is decreasing at $x=3$ because $f'(x)=-1<0$

2. State the range of values (interval) over which $f(x)=x-x^2$ is increasing
   $$f'(x)=1-2x$$
   $$1-2x>0 \to -2x>-1 \to x<\frac{1}{2}$$
