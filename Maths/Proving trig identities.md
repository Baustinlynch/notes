In maths, an **identity** is an equality relating one mathematical expression to another, such that both expressions produce the same value for all values of variable
For example:
$$(a+b)^2=a^2+2ab+b^2$$
Start with the Left Hand Side (LHS) and work with it until you get to the Right hand Side (RHS)
#### Examples:
1. Show that $\sin(180+a)\degree=-\sin a\degree$
   $LHS=\sin(180+a)\degree$
   $=\sin 180\cos a+\cos 180\sin a$
   $=0\times \cos a+(-1)\times \sin a$
   $=-\sin a\degree=RHS$
