# Helix

Creates a coil shape. A helix can be added or subtracted to a form.

![](https://user-cdn.hackclub-assets.com/01a0a93a-fa48-7922-a2c5-2d4978bc9efc/Helix1.png)

## Answering a helix question

![454](https://cdn.hackclub.com/01a0a93c-4d04-7db3-a4c3-16860c51c75c/Helix2.png)

1. Sketch a circle to dimensions shown
2. Sketch a line vertical to the shape as an axis and dimension the distance between the line and the center of the circle to 25mm
3. Use the helix tool to create a helix
4. Set the pitch of the helix to 15mm
5. Change the number of revolutions on the helix to 3
