# CAD File Types

Companies need to use file types that can be imported and exported into different software and programs.

## STEP/IGES
- 3D File Type - STEP files can be opened on any CAD modeling program
- STEP files can also be compressed easily
- Usually used for CAD library components

## DXF
- 2D file type - Are more universal than other 2D file types
- Often used for generating 2D gcode for laser cutters and routers

## 3DS
- 3D file types - A 3DS file is a file format used for modelling, animation and rendering software.
- The format has become industry standard for transferring models between 3D programs, or for sharing models for 3D resources.
