# Shell

Makes a model hollow, to a specific wall thickness.
One or more surfaces can be removed to create an opening.

## Answering a shell question
1. You will need to explain how you got the original shape before you started to use the shell tool
2. Using the shell tool, select to **remove** the top **surface** and **dimension to 3mm**
