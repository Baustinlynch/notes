# Extrude

When you extrude a profile it directly pulls up the **profile**/sketch and gives it 3D form.

## Answering an extrude question
1. Sketch a circle to the dimensions shown (diameter 50mm)
2. Extrude profile to 50mm
3. Sketch on the top surface a square to the dimensions shown (dimensions on each side to 10mm)
4. Extrude subtract the square profile to 30mm
