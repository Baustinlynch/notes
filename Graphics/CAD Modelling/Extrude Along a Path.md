# Extrude Along a Path

Extrude along a path is usually a long thin shape which only has one profile/doesn't change profile.
One of the best examples of this in practice is a paperclip, or anything using extruded aluminium.

## Answering an extrude along a path question

![404](https://cdn.hackclub.com/01a0a949-27b5-7e1a-90d4-ecdfa8ec0984/Path.png)

1. Sketch a profile to the dimensions shown
2. Create a work-plane perpendicular with the profile to 90°
3. Sketch path to dimensions shown on the new work-plane
4. Create an Extrude along a path by selecting the profile and the path
