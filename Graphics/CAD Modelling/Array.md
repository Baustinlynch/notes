# Array

Repeats a shape in a pattern.
Using an array as a modeling edit will allow you to repeat a feature in a linear, box or radial pattern. This can be quicker than sketching and extruding them all individually.

## Box array
Repeating in a 'square pattern'

## Linear array
Repeating in a line vertically or horizontally

## Radial array
Repeating in a circular pattern
