# Revolve

Revolves are shapes with cylindrical symmetrical shapes.
Draw half of the shape with an axis marking the point in the center. Revolve around the axis, this can be set to a specific degree if a full shape is not needed.

## Answering a revolve question
1. Sketch the profile to the dimensions shown
2. Using the Revolve tool select the profile and the center axis
3. Revolve the shape 270°
