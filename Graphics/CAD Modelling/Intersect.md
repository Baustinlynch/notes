# Intersect

Removes all material except the selected material. Part of the extrude feature.
Instead of subtracting or joining onto the original part, intersect keeps the material inside the extruded area.
If you imagine the material that an extrude subtract would cut away, that's what would be kept whilst using intersect.

(This is part of the production stage of the [[Course breakdown|Higher Graphics course]].)
