## CAD Libraries and stock models
#### CAD Library
A collection of pre-made 3D CAD models.
Pre-made items are called **stock models**. They are usually standard components which are used frequently. **This** saves the technicians time since they don't have to re-model the components each time. Also minimises errors in modelling. Can be pre-installed or found online.

#### 3D File formats
Stock models are often saved as file types that are **easily opened by all CAD software**. These files can be imported and exported and shared easily between technicians.

## Bottom-up and top-down modelling
There are two main approaches to modelling complex 3D assemblies:
1. Bottom-up
2. Top-down
So far, using CAD in school, you have been using bottom-up modelling.
#### Bottom-up
Individual parts are **separately** modelled from preliminary sketches. Next, the parts are gathered into an assembly. This approach relies on very accurate parts and a great deal of preliminary design work. **Errors** in the parts can be discovered during the assembly, where features might not line up properly. Errors can be time-consuming and expensive to fix.
#### Top-down modelling
The entire assembly is modelled. Each part is modelled in its proper place. Features, edges, sketches are shared between parts. Geometry is **projected** between parts to ensure perfect fits. A change in one component will be reflected in the rest of the assembly. This speeds up the process of creating complex assemblies. Individual parts can be exported from the assembly model.

Top-down modelling is a technique used by designers/engineers to ensure parts are **built** accurately. Top-down modelling means using one part to help model the next part. You can use top-down modelling by:
- Projecting geometry
- Mirroring features

##### Advantages
- Allows sizes to be captured from another part without measuring, making the model accurate.
- Allows geometry (the shape of something) to be captured without redrawing, making it faster to model.
- Ensures CAD modelling is assembled accurately as no constraints are required.
- Changes made to one part can automatically update another part, making it more accurate.

### Cloud computing
Cloud computing is the name given to the servers in data centres owned by **large corporations**.
#### Uses of the cloud
We use these servers to store our data such as emails, photos, and financial transactions.

#### Advantages
- Files can be accessed remotely from anywhere in the world.
- Allows for remote working.
- Files can be easily shared between coworkers.
- Allows for collaboration.
- Files can be encrypted.
- Requires no physical space.
- File versioning features.
#### Disadvantages
- It relies on the internet, so if there are connectivity issues, users may not be able to access their data or applications.
- It is vulnerable to cyber-attacks such as hacking.
- Users have limited control over the remotely located hardware.
- Can experience technical issues, such as downtime.
