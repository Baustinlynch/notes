We can use the resolution of a force to get the horizontal and vertical component of a vector by [[Resolving vectors]].
We use the same technique that we used in [[Projectiles]].
(Related: [[Connected Masses]] covers similar linked-body force problems, and [[Energy Conservation]] provides energy-based approaches to related scenarios.)

### Example:
![[Connected forces.excalidraw]]
1) For each tug:
   $F_h=R\cos\theta$
   $F_h=10,000\times\cos30^\circ$
   $F_h=8,660\ \text{N}$
   Total horizontal force:
   $F=8,660\times2$
   $F=17,320\ \text{N}$
2) Steady speed = Balanced forces
   Resistive forces = <u>$F=17,320\ \text{N}$</u>
