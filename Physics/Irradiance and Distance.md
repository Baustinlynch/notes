If we vary the distance of a point source from a detector, we produce a graph showing the inverse square relationship.
![[Drawing 2026-11-16 09.02.53.excalidraw]]
Which we can manipulate to give a linear graph:
![[Drawing 2026-11-16 09.05.52.excalidraw|327]]
$$I_{\text{irradiance}}\propto \frac{1}{d^2}$$
$$I = \frac{k}{d^2}$$
$$\text{Irradiance}=\frac{\text{constant}}{d^2}$$
This **is** in the data sheet.

#### Example:
1. A bulb shines onto a screen of a fixed area, 3 m away. $I$ at this point is $0.01\ \text{W/m}^2$. The bulb is moved to 1.5 m away, what is $I$ now?
   $I_1 d_1^2 = I_2 d_2^2$
   $0.01 \times 3^2 = I_2 \times 1.5^2$
   $0.09 = I_2 \times 2.25$
   $I_2 = \frac{0.01 \times 3^2}{1.5^2}$
   $I_2 = 0.04\ \text{W/m}^2$
