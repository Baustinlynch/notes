The purpose of the analysis stage is to get a **clear understanding of the program's requirements** (what they need to make for it to do all the things)

Requirements must specify:
- The data and instructions the program requires (**==inputs==**)
- what the program must do with the data and instructions (**==processes==**)
- The results **to be** displayed to the user (**==outputs==**)

The document created during the analysis stage is called the **software specification**. It defines **exactly** what the software must do
