The purpose of the analysis stage is to get a **clear understanding of the programs requirements**. 

The requirements must specify:
- The data and instructions the program requires(**inputs**)
- What the program does with the data and instructions(**processes**)
- The results to displayed to the user(outputs)

The document created during the analysis stage is called the **software specification**. The software specification outlines exactly what the software must do.
