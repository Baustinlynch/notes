Software can be designed and developed using the **waterfall model**.

The stages are : [[Analysis]], design, [[Implementation]] ,testing, documentation and maintenance. 

The software development process is know as an **iterative process**. This means that you can back to a previous stage as a result of information gained in a later stage. 
e.g.  an error found in testing can be fixed in implementation.
