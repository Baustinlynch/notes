
## Selection
Computer programs require selection to make decisions and execute different sets of instructions depending on the value of a variable.
e.g.
```
IF examMark >= 50 THEN
	SET result to "Pass"
ELSE 
	SET result to "Fail"
END IF
```

## Conditional Statements
examMark is an example of a conditional statement. All **Selection Statements** will have a conditional statement. Conditional statements are statements that are true or false. Condition statements ca be either **Simple or Complex**
### Simple
Depends on one condition statement being true or false:
```
IF speed > 70 THEN
	SEND "Well done, nice speed" TO DISPLAY
ELSE
	SEND "Too slow, speed up!" TO DISPLAY
END IF
```
### Complex
Depends on the result of two or more condition statements being true or false. Complex conditions make use of logical operators ()
