
## Selection
Computer programs require selection to make decisions and execute different sets of instructions depending on the value of a variable.
e.g.
```
IF examMark >= 50 THEN
    SET result TO "Pass"
ELSE
    SET result TO "Fail"
END IF
```

## Conditional Statements
**examMark >= 50** is an example of a conditional statement. All **selection statements** will have a conditional statement. Conditional statements are statements that are **either true or false**. Conditional statements can be either **simple or complex**.

### Simple
Depends on one conditional statement being true or false:
```
IF speed > 70 THEN
    SEND "Well done, nice speed" TO DISPLAY
ELSE
    SEND "Too slow, speed up!" TO DISPLAY
END IF
```

### Complex
Depends on the result of two or more conditional statements being true or false. Complex conditions make use of logical operators (**AND, OR, NOT**).
