
### Assignment
Assignment is the process of adding a value to a variable.
The value assigned to a variable can be either a constant value or the result of a calculation e.g.
```
SET discount TO 20
SET average to number1 + number2 + number3 / 3
```

### Concatenation
Joining strings together to make a new string. The "&" symbol is often used to concatenate strings e.g.
```
fullName = firstName & " " & lastName
```

### Sequence
Programs execute one line of code after another. Python programs execute in sequence
